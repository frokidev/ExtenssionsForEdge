# Extensions for Microsoft Edge

Kho lưu trữ tổng hợp các tiện ích mở rộng (Extensions) tùy biến cho trình duyệt **Microsoft Edge**.

---

## 📦 Danh sách Extensions

| Thư mục | Tên Extension | Mô tả |
| :--- | :--- | :--- |
| [`edge-compact-vertical-tabs/`](./edge-compact-vertical-tabs/) | **Edge Compact Vertical Tabs** | Hiển thị cột tab icon cố định ở Side Panel, hỗ trợ Mute/Unmute, không bao giờ tự dãn rộng khi hover. |

---

## 🛠️ Hướng dẫn cài đặt extension bất kỳ

1. Mở Microsoft Edge, truy cập `edge://extensions`.
2. Bật **Chế độ dành cho nhà phát triển** (*Developer mode*) ở cột trái.
3. Chọn **Tải phần mở rộng đã giải nén** (*Load unpacked*).
4. Điều hướng và chọn thư mục của extension cần cài đặt (ví dụ: `edge-compact-vertical-tabs`).
